# CYBERPULSE 360

### Global Cyber Threat Intelligence & Analytics Platform

**CYBERPULSE 360** is an end-to-end cybersecurity data analytics project designed to explore global cyber incidents, vulnerabilities, ransomware activity, and cybersecurity risk indicators using publicly available datasets.

## Project Objectives

- Analyze historical global cyber incidents.
- Explore country and industry-level threat patterns.
- Investigate vulnerability severity and exploitation.
- Analyze reported ransomware activity.
- Develop transparent cybersecurity risk indicators.
- Build interactive dashboards and analytical applications.

## Technology Stack

- Python
- Pandas & NumPy
- PostgreSQL
- Power BI
- Plotly
- Streamlit
- Scikit-learn
- Git & GitHub

## Project Architecture

Public Data Sources → Data Engineering → PostgreSQL → Python Analytics → Power BI & Streamlit
